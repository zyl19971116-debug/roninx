# RONIN X Asset Library

This directory is reserved for future RONIN X visual assets. Keep these files independent from the existing website assets until they are deliberately connected through the asset manifest.

## Directory purposes

- `character/` — Main RONIN character artwork.
- `crate/` — The single RONIN CRATE artwork.
- `weapons/` — Katana, swords, and secondary weapons.
- `helmets/` — Helmet and mask artwork.
- `armors/` — Armor and clothing artwork.
- `cores/` — Cyber core and energy core artwork.
- `back-items/` — Backpacks, sword holders, and back equipment.
- `accessories/` — Chips, charms, rings, and other accessories.
- `backgrounds/` — Homepage, crate page, forge, inventory, and market backgrounds.
- `effects/` — Glow, smoke, sparks, energy, particles, and other visual effects.
- `ui/` — RONIN X logo, icons, and other interface assets.

## Asset rules

1. PNG and WebP equipment assets should preferably have transparent backgrounds.
2. Use lowercase filenames.
3. Use hyphens instead of spaces.
4. Do not use Chinese characters in filenames.
5. Do not use random filenames such as `image1.png`.
6. Keep all future RONIN X visual assets inside this directory.
7. Do not mix these assets with existing website assets.
8. Do not reference these assets from the website until they are intentionally integrated.
